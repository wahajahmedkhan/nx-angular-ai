# Project Context

## Project Overview
This Angular project implements a chat interface that communicates with a Flowise AI backend. The application allows users to interact with an AI assistant through a chat interface, with the backend providing streaming responses that include both the AI's reasoning process and final responses.

## Environment Configuration
- Development API URLs are configured in `src/environment.ts`
- Production API URLs are configured in `src/environment.prod.ts`
- Backend is deployed at `http://akudeb.itserver.biz:3000` (Flowise API) and `http://akudeb.itserver.biz:3003` (Auth API)
- Alternative backend for testing: `http://65.21.84.168:3003`

## Key Files and Components

### Services

#### ChatService (`src/app/services/chat.service.ts`)
- Manages chat sessions and messages
- Handles communication with the Flowise API
- Implements streaming response handling
- Key methods:
  - `createNewChat()`: Creates a new chat session
  - `sendMessage(content: string)`: Sends a message to the Flowise API
  - `streamFlowWiseResponse(requestPayload, messageId)`: Handles streaming responses
  - `processStreamEvent(event, messageId, currentText)`: Processes different event types from the stream
  - `attemptToFixMalformedJson(jsonData)`: Attempts to fix malformed JSON in responses

#### AuthService (`src/app/services/auth.service.ts`)
- Manages user authentication
- Handles login, registration, and session management
- Stores authentication tokens in localStorage

### Models

#### Interfaces (`src/app/models/interfaces.ts`)
- `Message`: Represents a chat message
- `Chat`: Represents a chat session with messages and metadata
- `FlowWiseRequest`: Request payload for the Flowise API
- `FlowWiseResponse`: Response from the Flowise API
- `FlowWiseStreamEvent`: Represents different event types in the streaming response
- `AgentReasoningStep`: Represents a reasoning step from an agent
- `SourceDocument`: Represents a source document used by the AI

#### Flowise Interfaces (`src/app/models/flowise.interface.ts`)
- `ToolInput`: Input for a tool used by an agent
- `ToolOutput`: Output from a tool used by an agent
- `Tool`: Represents a tool used by an agent with input and output
- `SourceDocument`: Detailed structure for source documents with metadata
- `Artifact`: Represents artifacts generated by agents
- `State`: Represents the state of an agent including next steps and instructions
- `AgentData`: Comprehensive data structure for agent information
- `StartEvent`: Event indicating the start of a response
- `AgentReasoningEvent`: Event containing agent reasoning data
- `NextAgentEvent`: Event indicating the next agent to process
- `EventType`: Union type of all possible event types
- `ConversationItem`: Maps conversation items to event types

#### Enums (`src/app/models/enums.ts`)
- `MessageRole`: Defines roles (User, Assistant)
- `ChunkType`: Defines types of message chunks in streaming responses

## API Communication Flow
1. User sends a message to the chat interface
2. The application sends the message to the Flowise API
3. The API responds with a stream of events
4. The application processes these events to update the UI
5. The chat session ID and message ID are stored for continuity

## Event Types in Streaming Responses
- `start`: Indicates the start of a response
- `token`: Contains a token of the response text
- `agentReasoning`: Contains reasoning steps from an agent
- `nextAgent`: Indicates the next agent to process the request
- `sourceDocuments`: Contains source documents used by the agent
- `metadata`: Contains metadata about the chat session
- `end`: Indicates the end of the response

## Authentication Flow
1. User logs in with email and password
2. The application sends credentials to the Auth API
3. The API responds with an authentication token
4. The token is stored in localStorage and used for subsequent requests
